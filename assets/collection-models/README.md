# 红品收藏品 3D 网格

这些 GLB 文件由用户提供的 `UyNewNas-DeltaForceCompany-0.0.8.zip` 中的 Unity 网格导出并转换而来。`collection-catalog.json` 按收藏目录的 `item_id` 关联 48 件红品主展示模型；量子存储和实验数据各有一个可切换的第一人称视角模型。

转换保留几何、法线和可读 UV，并写入中性预览材质。源包未提供原始材质、贴图、Prefab 层级或动画，因此模型外观不会与游戏内完整渲染完全一致。模型以单件 GLB 按需加载；映射、源 OBJ 名称、顶点数和三角面数见同目录的 `manifest.json`。

这些游戏网格仍属于原游戏及相关权利人；此目录只记录该个人收藏数据库所用的预览资源，不授予其他用途的权利。
