## 方案对比、出战配装与收藏分享卡

- 在收藏页的武器方案夹展开“对比武器方案”，选择两套不同方案，查看武器、用途、预算、配装金额、备注、改枪码和截图。缺失预算不按零处理；不同游戏不计算货币差额。
- 新增或编辑武器方案时可填写最多 30 项配装，包括类别、名称、数量和单价。可按当前武器生成常用清单，也可逐项添加。配装合计按单价乘数量，缺价明确标注，方案预算和配装金额不自动相加。
- 方案卡片可展开配装单，勾选本次准备项或一键清空。准备状态仅保留于当前页面会话，切换账号时清理，不扣库存、不生成对局。配装明细随方案同步并进入 JSON 备份。
- 展柜卡片和普通收藏卡片的“更多”菜单都可生成收藏分享卡。先预览，再下载 1080×1440 PNG；系统支持文件分享时提供由用户点击的原生分享入口，也可长按预览图保存。
- 分享卡默认展示物品名、游戏及图片；库存、最早有效获取日期和展柜寄语默认不展示，可逐项勾选。不会自动加入账号、邮箱、物品私人备注、获取来源或完整历史。
- 外链图片受 CORS、网络或尺寸限制时使用图形占位并提示，不影响文字分享卡导出。切换账号、删除物品、关闭或重新生成预览会使旧的异步结果失效，并释放预览链接。
- 已使用真实 Canvas 渲染普通及超长名称分享卡检查布局。自动测试覆盖模型、表单、异步预览、文件导出和账号边界；iPhone 原生分享与页面视觉仍需实机验收。

## Arca 命名与轻量动效

- 应用内名称、网页标题、安装清单及 Apple 主屏幕安装名称统一为 Arca；内部存储键、云端表与现有备份格式保持兼容，应用版本不变。
- 个人展柜和武器方案夹采用 240 ms 展开、200 ms 收起，快速连续点击会取消旧动画并以最新操作为准；不会为动画复制表单。
- 页面切换为 160 ms 的轻微上移淡入；收藏进度变化平滑过渡，新增收藏种类/目标完成会给数字与圆环一次轻微反馈。入柜时只对该物品卡片播放出现动画。
- 尊重系统“减弱动态效果”，设置变化时立即结束正在运行的动效；无 Web Animations 支持时直接完成界面操作。动画不修改记录或库存。
- 已安装的主屏幕图标名称是否自动刷新由系统决定，网页更新成功不代表系统已同步图标标签。

## 个人收藏展柜与武器方案夹

- 收藏页顶部提供两个入口。展柜从已有物品中选取，支持搜索、500 字寄语、上移/下移和移出，最多 12 件；选入展柜不产生获取记录、不改变库存。未获得或已消耗的物品仍按真实库存显示。
- 加入展柜后自动在总览展示；可在自定义主页隐藏或长按拖动整个展柜模块。物品选择、寄语和柜内顺序跟随收藏记录同步，主页可见性与模块顺序延续原有按工作区保存于本机的规则。
- 武器方案支持名称、武器、游戏、用途、预算（游戏币）、改枪码、说明和一张改装截图，可搜索、编辑、删除和复制代码。改枪码由用户提供，不校验时效。
- 上传截图支持 PNG/JPEG/WebP、原文件最多 10 MB，压至最长边 1280 像素、数据 URL 最多 480000 字符；也可使用 HTTPS 图片链接。上传截图随方案写入本机记录、云同步和 JSON 备份，不建立公共图片桶。
- 方案使用独立的 `weapon_plan` 类型，不进入对局或收藏库存统计，也不参与匿名社区统计。数据库继续使用现有私有 JSONB 记录接口，无需迁移。
- 保存时本机容量不足会回滚；账号切换会清理编辑状态，过期的异步图片处理结果不应用到新工作区。编辑期间遇到方案远端更新时会要求重新打开编辑。

- JSON 导入先预览新增与跳过数量。同工作区已有 ID 不覆盖，跨工作区与旧备份创建新 ID，重置同步状态；重复副本按来源工作区与原 ID 跳过。待删除 ID 恢复为副本，保留原删除操作。
- 文件读取期间切换工作区会取消导入；存储失败不会部分更新内存。冲突副本深拷贝，获取明细互不串改。
- JSON 仍备份当前工作区的对局与收藏；不是全设备备份，不含其他工作区、草稿、删除队列及设置。
- CI 在 push / pull request 时运行 Node 回归测试；RLS、Auth 配置、社区 5 人 / 20 局门槛未调整。

## v0.6.1 截图识别导入

## v0.6.0 收藏簿

在“收藏”页记录任意游戏的收藏品、任务物品、皮肤、武器、装备或自定义分类。

- 物品清单：游戏、名称、分类、目标数量、可选 HTTPS 图片链接、备注。
- 获取日志：每次获取的日期、数量、来源或地图、本次总花费、备注。
- 进度由获取数量累计，自动显示未获得、已获得或已集齐；支持搜索与筛选。
- 物品和获取记录都可删除并在提示期间撤销；共用现有本地优先、账号隔离、云同步及冲突副本机制。
- JSON 备份包含全部对局与收藏；对局 CSV、收藏 CSV 分别导出。旧 JSON 不带 kind 的记录继续作为对局。
- 收藏不参与对局分析或社区统计；社区仍强制至少 5 个不同用户、20 局。

收藏以 `kind: collection` 存入现有 `fps_records.payload`，沿用原有 RLS、修订号与删除标记，无新增公开权限。获取日志随所属物品一起同步；并发修改会保留冲突副本。
