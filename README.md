## v0.6.5 同步与恢复可靠性

- 同步绑定启动时的账号与工作区代次；切换后不应用旧响应，也不继续旧上传批次。
- 首次上传期间删除会更新待删除版本，并保留 5 秒撤销窗口；云删除进行中撤销会重新上传恢复记录。
- 云端按 ID 排序，每页拉取 500 条；所有页面成功后才应用，删除队列不再截断到 1,000 条。
- JSON 导入先预览新增与跳过数量。同工作区已有 ID 不覆盖，跨工作区与旧备份创建新 ID，重置同步状态；重复副本按来源工作区与原 ID 跳过。待删除 ID 恢复为副本，保留原删除操作。
- 文件读取期间切换工作区会取消导入；存储失败不会部分更新内存。冲突副本深拷贝，获取明细互不串改。
- JSON 仍备份当前工作区的对局与收藏；不是全设备备份，不含其他工作区、草稿、删除队列及设置。
- CI 在 push / pull request 时运行 Node 回归测试；RLS、Auth 配置、社区 5 人 / 20 局门槛未调整。
